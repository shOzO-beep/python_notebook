=Блокнот для заметок на Python=

**Мой учебный проект на Python - консольный блокнот с функцией записи и обработкой ошибок.**

**Проект создан для практики программирования и закрепления знаний Python.**

=Возможности=

** Записать заметку **

** Просмотреть записаные заметки **

** Очистить записаные заметки **

** Обработка неправильного ввода **

** Возможность выйти из программы **


=Используемые технологии=

** Python **

** input() - ввод данных **

** if и elif - выбор действия **

** while - повторение программы **

** try и except - обработка ошибок**

** open with (...) as file - открытие файла **

** def - функции **


=Как запустить=

** 1. Установить Python 3.15.0 , если он ещё не установлен **

** 2. Скачать или клонировать этот репозиторий**

** 3. Открыть папку проекта в терминале

**    Для этого нужно щёлкнуть левой кнопкой мыши по пути к файлу и написать cmd **

** 4. В терминали запустить команду python notebook.py **

**    Если команда python не работает, попробуйте py notebook.py **
